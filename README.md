# Spatial-confinement-promotes-germinal-center-diversity-and-tempers-immunodominance
Code used to analyze scRNA-Seq data in "Spatial confinement promotes germinal center diversity and tempers immunodominance"


tree_ancestornodes_colored_evodist.R is used for plotting phylogenetic trees with tips colored by GC assignment and ancestor nodes colored by inferred GC assignment according to ACCTRAN
DE_venndiagram.R is used for Extended Figure 4E to plot overlapping DE genes
